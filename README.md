# 👥 CRUD de Funcionários

Sistema web para **gerenciamento de funcionários** com operações completas de CRUD (Criar, Ler, Atualizar e Deletar). Desenvolvido com **JavaScript** no front-end, **C#** no back-end e **SQL Server** como banco de dados.

---

## ✨ Funcionalidades

- **Cadastrar** novos funcionários
- **Listar** todos os funcionários cadastrados
- **Editar** informações de um funcionário existente
- **Excluir** funcionários do sistema
- Interface web responsiva com HTML e CSS

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia    | Uso                              |
|---------------|----------------------------------|
| JavaScript    | Lógica e interações do front-end |
| C#            | Lógica do back-end               |
| HTML/CSS      | Estrutura e estilo da interface  |
| SQL Server    | Banco de dados relacional        |
| T-SQL         | Scripts de banco de dados        |

---

## 📋 Pré-requisitos

- [Visual Studio](https://visualstudio.microsoft.com/) ou [VS Code](https://code.visualstudio.com/)
- [SQL Server](https://www.microsoft.com/pt-br/sql-server) instalado e configurado
- .NET compatível com o projeto

---

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Dravvos/CRUD-Funcionarios.git
   ```

2. **Configure o banco de dados:**
   - Navegue até a pasta `Database Project`
   - Execute os scripts SQL para criar as tabelas necessárias no SQL Server

3. **Configure a conexão com o banco:**
   - Abra o projeto back-end e atualize a string de conexão com os dados do seu servidor SQL

4. **Execute o projeto:**
   - Abra no Visual Studio, compile e execute
   - Acesse a aplicação pelo navegador
